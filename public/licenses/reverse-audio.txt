REVERSE WORD GAME: AUDIO AND WORD BANK PROVENANCE

The 600 WAV files in /reverse-words/ are newly synthesized pronunciations of
ordinary English words, not recordings of a person. They were generated offline
using the built-in en-us formant voice of eSpeak NG 1.52.0, through
@spelling-creator/spellophone 0.2.1. No Apple, commercial, MBROLA, or cloned voice
was used. No speech service, API key, runtime synthesis model, or billing is
required to play these clips. The synthesis engine is not shipped with this site.

WORD SELECTION AND SYLLABLE VALIDATION

The word bank was curated for familiar everyday vocabulary. Syllables were
checked against CMUdict by counting vowels with a 0, 1, or 2 stress marker.
Words with dictionary variants having different syllable counts were excluded.
Counts use American English dictionary pronunciations; accents may differ.
There are 160 one-syllable, 150 two-syllable, 150 three-syllable, and
140 four-syllable words. CMUdict is BSD licensed; its required notice is in
reverse-audio-cmudict-LICENSE.txt.

Dictionary source (pinned revision):

AUDIO FORMAT AND COST

Each file is mono, 16,000 Hz, signed 16-bit PCM WAV. Speech uses rate 150 and
pitch 50. Near-silence is trimmed with 25 ms padding, and a windowed-sinc low-pass
resampler converts eSpeak's 22,050 Hz output to 16,000 Hz. The complete bank is
11,591,372 bytes (about 11.1 MiB); individual files average 19.3 KB and are at
most 34.4 KB. Only the selected round's clip needs downloading from the site's
static hosting. These files do not consume Firebase database bandwidth.

REGENERATING (DEVELOPER MACHINE ONLY)

Use Node.js 24 or newer. Install the pinned generator into a temporary directory
outside the website's application dependencies:

  npm install --prefix /tmp/reverse-audio-tools --ignore-scripts @spelling-creator/spellophone@0.2.1

Download the pinned CMUdict source above to /tmp/reverse-audio-tools/cmudict.dict.
From the repository root, run:

  node scripts/generate-reverse-audio.mjs --engine /tmp/reverse-audio-tools/node_modules/@spelling-creator/spellophone/dist/node.js --dictionary /tmp/reverse-audio-tools/cmudict.dict

The script validates syllable counts and uniqueness before writing any files.
It uses only offline synthesis after the development tools have been downloaded.
Do not copy the temporary engine installation into the site's public directory.
