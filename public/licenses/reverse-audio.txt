REVERSE WORD GAME: NATURAL NEURAL AUDIO AND WORD BANK PROVENANCE

The 600 WAV files in /reverse-words/ are newly synthesized pronunciations of
ordinary English words. They use Kokoro-82M v1.0, an 82-million-parameter neural
text-to-speech model, with its af_heart American English voice. They are not
recordings of a person. The old eSpeak formant-synthesis clips have been replaced.

Generation runs offline on the developer machine using the full-precision
(fp32) ONNX neural model, kokoro-js 1.2.1, and Transformers.js 3.8.1. The model
and Kokoro code are Apache-2.0 licensed. The selected model revision is pinned:

WORD SELECTION AND SYLLABLE VALIDATION

The bank contains familiar everyday vocabulary checked against CMUdict by
counting vowels with a 0, 1, or 2 stress marker. Words with dictionary variants
having different syllable counts were excluded. Counts use American English
dictionary pronunciations; accents may differ. There are 160 one-syllable,
150 two-syllable, 150 three-syllable, and 140 four-syllable words. CMUdict is BSD
licensed; its required notice is in reverse-audio-cmudict-LICENSE.txt.

Dictionary source (pinned revision):
https://raw.githubusercontent.com/cmusphinx/cmudict/0f8072f814306c5ee4fbf992ed853601b12c01f9/cmudict.dict

AUDIO FORMAT AND COST

Files retain the model's native 24,000 Hz sample rate, mono signed 16-bit PCM
WAV with a standard 44-byte header. Speaking speed is 0.95. Near-silence below
-60 dB is trimmed with 40 ms padding, preserving quiet consonants. No resampling,
voice changer, or lossy audio encoding is applied. The complete per-file SHA-256,
size, and duration record is in reverse-audio-manifest.json.
The complete bank is 22,309,258 bytes (about 21.3 MiB); individual clips average
37.2 KB and are at most 54.8 KB, lasting 0.59-1.14 seconds each.

Only the selected round's small clip is downloaded from the site's static
hosting. The word pronunciations use no Firebase database bandwidth, speech API,
paid service, or runtime model on the player's phone. User microphone recordings
are separate from these generated static word-pronunciation assets.

REGENERATING (DEVELOPER MACHINE ONLY)

Use a current Node.js version. Install the pinned generator into a temporary
directory outside the website's application dependencies:

  npm install --prefix /tmp/reverse-neural-tools kokoro-js@1.2.1 @huggingface/transformers@3.8.1

Download the pinned CMUdict source above to /tmp/reverse-neural-tools/cmudict.dict.
From the repository root, run:

  node scripts/generate-reverse-audio.mjs --tools /tmp/reverse-neural-tools --dictionary /tmp/reverse-neural-tools/cmudict.dict

The first run downloads the free, pinned neural model to the temporary tools
folder. All synthesis runs locally. Subsequent runs can use that download cache.
The script validates syllable counts and uniqueness before writing audio. It
writes every waveform using the neural model and updates the per-file manifest.
Do not copy the temporary tools/cache/model files into the site's public folder.
